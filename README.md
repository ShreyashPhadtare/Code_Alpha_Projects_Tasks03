### Description

Data Visualization is the process of transforming raw data into meaningful visual representations such as charts, graphs, and dashboards. In this task, I will use Python libraries such as Matplotlib, Seaborn, and Pandas to analyze data and create clear, informative visualizations. The goal is to identify trends, patterns, and relationships in the data, communicate insights effectively, and support data-driven decision-making.

### Extended Description

* Clean and prepare the dataset for visualization.
* Create charts and graphs using Matplotlib and Seaborn.
* Identify trends, patterns, and relationships in the data.
* Design clear and visually appealing visualizations.
* Present key findings through data storytelling.
* Build a portfolio showcasing practical data visualization skills.
